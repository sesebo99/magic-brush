# マジックブラシ 完成版 Vercel + Hugging Face Inference Providers で動かす簡易AI画像編集アプリです。 ## ファイル構成 ```text magic-brush/ ├─ public/ │ └─ index.html ├─ api/ │ └─ hf-inpaint.js └─ package.json ``` ## Vercelへの設定 1. この3ファイルをVercelプロジェクトに配置 2. Deploy 3. Vercel Project Settings → Environment Variables 4. `HF_TOKEN` を追加 5. Hugging Faceのトークンには Inference Providers を利用できる権限を付ける 6. Redeploy ## 使い方 1. 写真を選択 2. 指で変更したい場所を赤く塗る 3. 「a cat」など英語で変更内容を書く 4. 「書き換え実行」 ## 重要 現在のHugging Face Inference ProvidersのImage-to-Imageを使用しています。 この方式は旧 `api-inference.huggingface.co/models/...` 方式を使用しません。 マジックブラシの「マスク」はVercel側で編集範囲の矩形を求めるために使います。 AIには選択範囲＋周囲の一部を渡し、生成結果をその矩形だけ元画像に合成します。 そのため、厳密なStable Diffusion Inpaintingの「白マスク部分だけ生成」とは異なります。 また、Hugging Face Inference Providersには無料の利用枠がありますが、無制限無料ではありません。
